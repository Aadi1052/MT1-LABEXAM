🛒 Shopping Cart Management

Welcome to our Shopping Cart Application!

✅ Served using Node.js FS Module (/home)

Part A: Node.js HTTP Server

Running on http://localhost:3000 using native http & fs

  • GET /
    HTML Welcome Page
  • GET /cart
    Shopping Cart (JSON)
  • GET /about
    About Application
  • GET /home
    Static HTML (FS Module)
  • POST /add-to-cart
    Add Item (JSON)

Part B: Express.js REST API

Running on http://localhost:4000 with CRUD operations

  • GET /cart
    Retrieve all items
  • GET /cart/:id
    Retrieve item by ID
  • POST /cart
    Add new product (201)
  • PUT /cart/:id
    Update product
  • DELETE /cart/:id
    Remove product
